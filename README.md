# 🏠 سيرفر البيت الذكي للطباعة والمشاركة (Smart Home Server)

سيرفر ويب محلي متكامل للطباعة اللاسلكية المباشرة لطابعة **Ricoh Aficio SP C252SF** ومشاركة الملفات ومراقبة أجهزة الواي فاي المنزلية.

## ✨ المميزات الرئيسية
- 🖨️ **مركز طباعة متقدم (One-Click Print):**
  - معاينة حية على ورقة A4 قبل الطباعة.
  - تحكم حر في الاسترتش والتحجيم (Scale & Stretch).
  - إمكانية الطباعة بدون حواف نهائياً (0mm Borderless).
  - دعم الطباعة وش وضهر تلقائياً (Duplex / Two-sided).
  - تحديد الصفحات بدقة (الكل، فردي، زوجي، أو نطاق مخصص مثل `1-5, 8`).
  - دعم الألوان أو الأبيض والأسود لتوفير الحبر.
- 📶 **رادار أجهزة الشبكة (Network Radar):** اكتشاف كل الأجهزة المتصلة بالواي فاي وعناوين الـ IP والـ MAC.
- 📁 **سحابة الملفات المنزلية (Family Cloud):** مشاركة الملفات ونقلها بين الموبايلات واللابتوب.

## 🚀 طريقة التشغيل
اضغط نقراً مزدوجاً على ملف:
```cmd
run_server.bat
```
أو عبر بايثون:
```bash
python home_server.py
```
ثم افتح الرابط: `http://localhost:5000` أو من الموبايل `http://<IP-ADDRESS>:5000`.
